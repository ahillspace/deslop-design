How to read this sample

The supplied screening threshold is 4.0 mg/L nitrate-N. Readings above it are East Weir and Lower Mill; Bay Outlet is equal to it. South Marsh has no recorded value and is not counted as zero.

The sample does not establish a trend or a health effect.

Method

Grab samples were collected once at each listed station on 4 April 2026 and analyzed by the field team's standard colorimetric procedure. One station value is missing because the instrument result was not recorded. No repeat sample is available in this file.
