# Sources and licensing boundary

This register traces selected mechanisms without treating external projects as interchangeable instruction libraries.
The current source review was completed on 29 October 2026.
It covers the exact repository files and licenses at the recorded commits for this synthesis.
It is source inspection, not comparative proof of output quality.

All skill instructions, examples, and checker code in this repository are original package text.
The register records conceptual inspiration rather than reproduced passages, source code, templates, screenshots, fonts, or images.
The package makes no claim that these upstream works are relicensed under its MIT license.
The article is linked as evidence and its text is not republished.
If a future change incorporates upstream expression, code, or assets, record the file, modifications, governing terms, and required notices with that change.
