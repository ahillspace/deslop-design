# Sources and licensing boundary

This register helps maintainers trace mechanisms without treating external projects as interchangeable instruction libraries.
The source review was completed on 28 October 2026; these links pin the versions used for the initial synthesis.
It was source inspection, not comparative proof of output quality.

All skill instructions, examples, documentation, and checker code in this repository were written for this package.
The table records conceptual inspiration: workflow ideas were selected and implemented in new prose, rather than importing or paraphrasing source instruction blocks as a derivative manual.
No upstream instruction passages, code, templates, screenshots, fonts, or images are distributed here.
There is no adapted copyrightable source expression claimed under the repository's MIT license.
The standard MIT license text is the legal grant for this package's original work.
If a future change actually incorporates external expression or assets, record the file, modifications, governing terms, and required notices with that change; this conceptual-source register does not replace those obligations.

Original MIT licensing is compatible with consulting these permissively licensed sources; it does not relicense the linked projects.
Public galleries and repository screenshots do not grant rights to the depicted work.
Each asset used in a downstream artifact still needs its own rights check, required credit, and modification record.
No external asset is licensed by this repository.

## Evidence limits retained from the research

The source review screened 27 repositories, but this package includes only the selected mechanism register above.
The review's local retrieval and style-linter probes did not measure complete skill performance.
A retrieval generator's successful exit did not ensure genre fit, and a style detector could reject legitimate analytical devices.
Taste Skill's gallery study used model reviewers and selected still images; its reported results were mixed, not independent human proof.
The source-stage browser attempt failed, so it supplied no rendered evidence.
This package's later smoke trial is reported separately in [validation](validation.md).

Existing browser automation can gather screenshots, DOM, styles, and interactions; an accessibility scanner supplies only part of an accessibility assessment.
See [W3C's evaluation-tool limits](https://www.w3.org/WAI/test-evaluate/tools/selecting/).
No new browser software is bundled or required by name.
This register is not a complete legal or security audit of upstream projects.
